
# DreamcastDroid Device Configuration

Experimental Android 4.0 device configuration for the Sega Dreamcast.

## Target
- CPU: Hitachi SH-4
- Platform: Sega Dreamcast
- Android base: Ice Cream Sandwich (4.0)

## Planned configuration
- [ ] Device makefile and product definition
- [ ] Init configuration
- [ ] Filesystem and mount layout
- [ ] Controller input configuration
- [ ] Framebuffer/display configuration
- [ ] Ethernet configuration
- [ ] AICA audio integration
- [ ] vold and persistent-storage configuration

## Dependencies
- Android ICS source tree
- SH-4 Linux kernel and compatible userspace
- Dreamcast hardware support

## Status
Planning only. No working Android target exists yet.
